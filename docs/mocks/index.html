What I looked at

Which theme

Editorial data tracker. A calm paper page (white first, dark as the switch), ink text, and color spent only on meaning:

PieceChoice
Status✕ Not taking · ! Restricted · ? Needs re-check · ✓ Back open. Always icon plus label, never color alone. These four colors mean nothing else anywhere.
AmountsOne blue ramp for counts (map, inline bars). Blue so it never reads as a status.
TypeSystem sans for UI and every chart. A serif only for story headlines.
ChartsStatus strips, timelines, a level matrix, the explainer bar, coverage bars, a tile map. Thin marks, hairline grids, labels in ink, a source line under each.
VoicePlain words in data. The Gen Z voice moves to headlines and empty states only.
ModeWhite first: charts read best on paper and news sites set the expectation. Dark is a full theme, not an inversion.
